## 🌸 Task 3: Iris Flower Classification

### 📌 Objective

Build a machine learning model to classify iris flowers into three species — Setosa, Versicolor, and Virginica — based on their sepal and petal measurements.

---

### 📊 Dataset

The dataset used is the built-in Iris dataset available in **scikit-learn**.

It contains:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Target (Flower Species)

---

### ⚙️ Technologies Used

* Python
* Pandas
* Scikit-learn

---

### 🔄 Steps Performed

1. Loaded the Iris dataset using sklearn
2. Converted dataset into a Pandas DataFrame
3. Split data into features (X) and target (y)
4. Divided dataset into training and testing sets
5. Trained model using Logistic Regression
6. Predicted results on test data
7. Evaluated model using accuracy score

---

### 📈 Model Used

* Logistic Regression

---

### ✅ Result

* Accuracy: 1.0

The model successfully classifies iris flowers with high accuracy.
