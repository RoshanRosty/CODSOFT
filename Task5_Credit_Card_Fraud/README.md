# 💳 Task 5: Credit Card Fraud Detection

## 🎯 Objective
Build a machine learning model to detect fraudulent credit card transactions.

---

## 📁 Dataset
The dataset contains transaction details with features such as time, amount, and anonymized variables (V1–V28).

- **Class = 0** → Normal transaction  
- **Class = 1** → Fraud transaction  

---

## ⚠️ Problem
The dataset is highly imbalanced, with very few fraud cases compared to normal transactions.

---

## 🔍 Steps Performed

1. Data loading and exploration  
2. Checked class imbalance  
3. Data visualization  
4. Train-test split  
5. Handled imbalance using upsampling  
6. Model training using Logistic Regression  
7. Model evaluation using:
   - Confusion Matrix  
   - Precision  
   - Recall  
   - F1 Score  

---

## 🤖 Model Used
- Logistic Regression

---

## 📊 Results
The model is able to identify fraudulent transactions with good precision and recall after balancing the dataset.

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  

---

## 📌 Conclusion
This project demonstrates how machine learning can be used to detect fraud in financial transactions and highlights the importance of handling imbalanced datasets.
