# 📊 Task 4: Sales Prediction using Python

## 🎯 Objective
The objective of this project is to build a machine learning model that predicts product sales based on advertising expenditure on different platforms such as TV, Radio, and Newspaper.

---

## 📁 Dataset
The dataset contains the following features:
- **TV** – Advertising budget spent on TV
- **Radio** – Advertising budget spent on Radio
- **Newspaper** – Advertising budget spent on Newspaper
- **Sales** – Sales of the product (Target Variable)

---

## 🔍 Project Workflow

1. **Data Loading**
   - Loaded dataset using Pandas

2. **Data Exploration**
   - Checked dataset structure using `.info()` and `.describe()`
   - Verified missing values

3. **Data Visualization**
   - Used Seaborn and Matplotlib
   - Observed relationships between features and sales

4. **Feature Selection**
   - Selected TV, Radio, Newspaper as input features
   - Sales as output variable

5. **Train-Test Split**
   - Split dataset into training and testing sets (80:20)

6. **Model Building**
   - Used **Linear Regression**

7. **Model Evaluation**
   - Evaluated using:
     - Mean Absolute Error (MAE)
     - Mean Squared Error (MSE)
     - R² Score

---

## 🤖 Model Used
- **Linear Regression**

---

## 📈 Results

- The model successfully predicts sales based on advertising budgets.
- Lower MAE and MSE indicate good prediction accuracy.
- R² score shows how well the model fits the data.

---

- Scikit-learn

This project demonstrates how machine learning can be used to predict sales and help businesses make better marketing decisions based on advertising investments.
